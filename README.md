# 暗号化ファイルの復元

このフォルダーを、`packages` フォルダーとその中の連番ファイルも含めて丸ごと保存してください。復元にはWindowsと7-Zip、作成時のパスワードが必要です。

1. `Restore.cmd` をダブルクリックしてください。
2. パスワードを入力してください。入力文字は表示されません。
3. `PASS: restored and verified ... files.` が表示されるまで待ってください。
4. 作成された復元先フォルダー内の `README.md` を開いてください。

同じ32桁の英数字で始まる `.7z.001`、`.7z.002` などは1組です。復元には各組の連番ファイルがすべて必要です。通常は `Restore.cmd` が全組を順に展開するため、個別に操作する必要はありません。

復元処理は各ファイルのサイズとSHA-256を確認し、最後に元の内容との一致を確認します。既存の復元先には上書きせず、新しい日時のフォルダーを作成します。空き容量が不足している場合やファイルが欠けている場合は停止します。

受け渡しにはこのフォルダーの中身一式を使ってください。
